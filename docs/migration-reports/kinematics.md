## Substantive corrections and evidence

1. **DLT projection:** image coordinates require a point-dependent homogeneous scale, `s [u,v,1]^T = P [X,Y,Z,1]^T`. DLT is a linear estimation procedure for the homogeneous projective model; pixel projection includes division. Calibrating one camera from known 3D points differs from reconstructing an unknown 3D point from multiple views. A last-entry-equals-one normalization also requires that entry to be nonzero. Evidence: [OpenCV 4.x camera model](https://docs.opencv.org/4.x/d9/d0c/group__calib3d.html), opened 2026-10-22 (redirected to 4.13.0).
2. **SVD rotation:** `U @ V.T` can have determinant −1. The text now includes the determinant correction and cross-covariance transpose convention. Evidence: [Lynch and Park, rotation matrices](https://modernrobotics.northwestern.edu/nu-gm-book-resource/3-2-1-rotation-matrices-part-1-of-2/), opened 2026-10-22; the notebook's supplied helper already implements the proper-rotation constraint.
3. **Froude notation:** the guide distinguishes dimensionless speed `v/sqrt(gL)` from the commonly used locomotion Froude convention `v²/(gL)`, while acknowledging that naming varies by source. Evidence: [Dynamic similarity during human running](https://www.sciencedirect.com/science/article/pii/S0021929008005848) and [Alexander and Jayes 1983](https://zslpublications.onlinelibrary.wiley.com/doi/10.1111/j.1469-7998.1983.tb04266.x). The equation, rather than the label alone, determines the comparison.
4. **Gait/dementia statement:** the original wording described a memory test and implied identifying individuals who will develop dementia. The primary study uses slow gait plus cognitive complaints and reports association with risk, not individual certainty. Evidence: [Verghese et al. 2014](https://www.neurology.org/doi/10.1212/WNL.0000000000000717), primary search result checked 2026-10-22.
5. **Special gimbal-lock input:** AngularVelocity3D's specified body vector `(0,0,1)` at gamma=0 has rates `(0,0,1)` for every nonsingular beta; it does not exhibit the divergence that the prompt might suggest. At beta=90° the rates are nonunique. Independently checked against the notebook's symbolic rate matrix; the answer also gives `(sec(beta),0,-tan(beta))` for the divergent `(1,0,0)` input.
6. **Noisy tibial-tuberosity marker:** `e1s` does not depend on TT; `e2s` and `e3s` rotate together and have equal angular error. With seed 0, 5 mm noise and the original recording, the altered axes have median 0.540°, 95th percentile 1.396° and maximum 2.340°. The answer corrects the question's implication that one altered axis must be uniquely most sensitive.
7. **Ellipsoid rotation integrity:** 0.70/0.71 entries in the singular example did not form an exactly orthogonal matrix. Exact `sqrt(0.5)` entries restore orthogonality. Cross-product closure preserves a right-handed triad generally; for the supplied landmarks it agrees with the original numerical orientation (determinant +1). Physical plot aspect is now equal.
8. **Dataset/convention issues:** the original 20 m sprint table has times differing slightly from the 10 m table; the comparison now separates source differences from sampling resolution. The gymnast's range now explicitly depends on landing centre-of-mass height. All newly computed Winter foot plots use MT5-to-heel/TOE-to-heel directions and the +90° ankle offset shown in the original figure.
9. **Obsolete navigation/requirements:** internal links in this group now target `.py`; the obsolete PolarBasis Colab badge was removed; old Tracker, lab and Neurology URLs were updated; SkillSpector remains identified as historical rather than an installation recommendation; DLT no longer asks readers to install an optional package already embedded in the notebook. ### Additional correction evidence

- **Kistler COP polynomial:** the [manufacturer's 9287C manual, section 8.4.3](https://assets.kistler.com.cn/SAPCommerce_Download_original/002-462e.pdf) specifies both corrections from measured `axm, aym` and gives the coefficients retained in this repository. Its coordinate/error units are millimetres. The implementation previously evaluated those coefficients on metres and used already-corrected x for the y polynomial. It now evaluates both from measured millimetre coordinates and returns metres. An independent type-3 case with measured (100, 50) mm has corrections (−5.1842329375, 6.095278625) mm and corrected COP (105.1842329375, 43.904721375) mm. This is covered by a regression. The retained recording stays in contact throughout (Fz about 418.55–470.28 N), so its corrected plots do not rely on unloading samples.
- **Kistler semantics and setup:** [manufacturer formula sheet](https://isbweb.org/software/movanal/vaughan/kistler.pdf), page 1, distinguishes surface moments, origin Mz and free moment Tz. [Qualisys Kistler settings](https://docs.qualisys.com/qtm/content/project_options/force_plate_settings_kistler.htm) documents the need for actual calibration, geometry and amplifier settings. NumPy-array calibration and origin arguments now use explicit `is None` checks; a single sensitivity row now follows its documented range-independent behavior.
- **Zebris source limits:** [2015 FDM manual](https://www.zebris.de/fileadmin/Editoren/zebris-PDF-Manuals/Medizin/Hardware/Alte_Versionen/FDM_Hardware-Manual_151203_en.pdf) supplies the model-specific sensor area/frequency comparison. Actual fixture headers establish the grid dimensions and 8.46591 mm spacing; actual 0.5-valued entries disprove a universal >1 threshold claim. The APD maximum-map counterexample proves that summed per-sensor maxima need not equal maximum simultaneous force. [Matplotlib imshow documentation](https://matplotlib.org/stable/api/_as_gen/matplotlib.axes.Axes.imshow.html), fetched through Context7 `/websites/matplotlib_stable`, confirms `extent` is the physical bounding box and interpolation affects image rendering.
- **Calibration mathematics:** dimensional analysis of the retained six-component load equation gives the mixed block units. The stopping criterion must require all absolute changes to be small, so continuation uses `any(delta > tolerance)`. A real noiseless five-site regression with a stationary centre site stopped after one iteration in the old code and had a maximum coefficient error of 0.825617; the correction recovers the identity within 1e-4 and returns a matrix recomputed from the final angles. [SciPy pinv](https://docs.scipy.org/doc/scipy/reference/generated/scipy.linalg.pinv.html) and the 1.7 deprecation notes were checked through Context7 `/scipy/scipy`; current `pinv` uses SVD and subsumes removed `pinv2`. The legacy `method` selector is now accurately documented as using the current same solver in both branches.
- **Nonlinear status:** [Cappello et al. 2011](https://pubmed.ncbi.nlm.nih.gov/21392999/) describes training/validation of a position-dependent recalibration. The original notebook's draft repeats linear fitting and never estimates Cx/Cy. That limitation is made visible in the learner's flow and remains a future extension, not a claimed completed nonlinear implementation.
- **Similarity edge cases:** the shared/embedded MSE implementations now broadcast an explicitly supplied target along the sample axis. For a zero normalization scale they retain zero error as zero and positive error as infinity, preserving missing-trial NaNs. Automatic threshold quantiles exclude infinite values, so the zero-baseline case can still remove a differing trial. Regressions cover identical trials, one different trial, and target evaluation with trials in columns or rows.
