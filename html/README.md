# Static HTML preview

[Open Body segment parameters](https://bmclab.github.io/BMC/html/body_segment_parameters.html)
or open `body_segment_parameters.html` locally in a browser.

This first example contains saved text, tables and plots. It can be read without
Python, molab or marimo.app. Expandable exercise solutions remain available.
The two badges at the top open the corresponding notebook in molab or marimo.app
when interactive execution is wanted.

The HTML uses marimo's display assets from a CDN and the original image links,
so an Internet connection is still needed for those resources. Neither notebook
execution service is needed to read the page.

The source remains [notebooks/body_segment_parameters.py](../notebooks/body_segment_parameters.py).
Only this notebook has been exported for review; the rest of the collection is
unchanged.
